# FastAPI Mini App

A simple FastAPI application for user authentication, PDF upload, PDF text extraction, summary generation, and quiz generation.

## Features

- User registration
- JWT authentication
- Password hashing
- SQLite database
- PDF upload
- PDF text extraction using PyMuPDF
- Basic summary generation
- Quiz generation
- Swagger API documentation
